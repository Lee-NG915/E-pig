# M2.3 PRD — 搜索

更新日期：2026-07-18

状态：proposal  
Phase：2  
依赖：M2.1 listing 契约；建议 CatalogPort 或 SearchPort  
参考工程锚点：`(PLP)/search`、search module；生产用 ES（01 §3）— E-pig **不**引入 ES

## 1. 目标

提供站内 **搜索 query**：用户输入关键词，得到结果列表（复用 listing UI），含空态；数据来自 mock（内存过滤或简单打分即可）。

## 2. 范围

- 路由：如 `/search?q=`。
- Port：优先 `SearchPort.search({ query, marketId })`；若极简可暂挂 `CatalogPort`，但 modules 仍不直连 adapter。
- UI：搜索框（Header 或搜索页）、结果网格、空态文案。
- 测试：命中 / 无命中；query 编码。

## 3. 非目标

- Elasticsearch、Searchkit、InstantSearch、拼写纠错、个性化、DY。

## 4. 验收标准

| # | 条目 | 门槛 |
| --- | --- | --- |
| 1 | `/search?q=` 可展示与 query 相关的结果 | **是** |
| 2 | 无命中有空态 | **是** |
| 3 | Header（或等价）可发起搜索 | **是** |
| 4 | 结果项复用 listing 卡片契约 | **是** |
| 5 | 至少 2 个自动测试（命中/空） | 否 |
| 6 | 无 ES/Algolia 等外部搜索依赖 | **是** |

## 5. 参考工程对齐要点

- 复现「搜索是独立能力入口 + 列表复用」；用 mock 替代 ES。

## 6. 风险

- 若与 PLP 卡片 props 不一致，视觉与测试双倍维护。

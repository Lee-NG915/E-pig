# M2.2 PRD — PDP + Variant

更新日期：2026-07-18

状态：proposal  
Phase：2  
依赖：M2.1（至少有稳定 slug 列表契约）  
参考工程锚点：`(pdp)/products/[slug]`、product domain/services（01 §2.2、§4）

## 1. 目标

提供 **PDP**：展示商品详情、图库（可最小为单图+缩略）、价格、短描述；支持 **variant 选择**（如尺寸/颜色 mock 维度），选择后价格/可售状态与加购参数一致。

## 2. 范围

- 路由：如 `/products/[slug]`。
- CatalogPort 扩展：`getProductBySlug`（或等价）返回 detail + variants。
- UI：标题、价格、variant 控件、Add to cart CTA（可先打到现有 cart 演示；M2.4 再切 Server Action）。
- 404：未知 slug。
- 测试：variant 切换改变展示价格或 sku；未知 slug 行为。

## 3. 非目标

- 完整 3D/巨量图库、warranty、CMS data-bucket、真实库存源、Checkout。

## 4. 验收标准

| # | 条目 | 门槛 |
| --- | --- | --- |
| 1 | 从 PLP 可进入 PDP 且 slug 正确 | **是** |
| 2 | PDP 展示名称、价格、至少一张图、加购入口 | **是** |
| 3 | 至少一类 variant 可切换，并影响加购标识（variantId/sku） | **是** |
| 4 | 未知 slug → notFound/404 | **是** |
| 5 | 组件或集成测试覆盖 variant → 加购参数 | 否 |
| 6 | 无 modules→adapters 越界 | **是** |

## 5. 参考工程对齐要点

- 复现「详情页服务端取数 + 客户端 variant 交互」分层。
- 不复制 Storyblok PDP widgets / Mulberry warranty 等周边。

## 6. 风险

- 加购若仍写 localStorage，M2.4 需迁移路径；PDP CTA 应抽象为 `addItem(input)` 以免双写。

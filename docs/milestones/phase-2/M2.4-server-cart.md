# M2.4 PRD — Server Cart + 匿名 Cookie

更新日期：2026-07-18

状态：proposal  
Phase：2  
依赖：M2.2 加购输入（variantId/sku）；强烈依赖 `docs/codex/research/07` cart 决策  
参考工程锚点：cart actions / services、cookie 会话；Redux cart 为参考工程客户端侧 — E-pig 用 Server Action + port

## 1. 目标

将演示用 localStorage cart **升级为服务端购物车**：

- 首次 `addItem` mutation 时懒创建匿名 cart 并签发**签名 cookie**
- 刷新页面后 cart 恢复
- 并发 add 具备幂等/不丢项的测试保护
- `proxy.ts` / 中间层 **不得**在 GET 时创建 cart（07 Hard Rule）

## 2. 范围

- CartPort 方法对齐：create/get/addItem/update/remove（按现有 contract 扩展）。
- Server Actions 或 Route Handlers：只在 mutation 路径设 cookie。
- Client：TanStack Query（或等价）拉取/失效 cart；UI 接现有 cart sheet。
- 迁移：旧 localStorage key 可读一次后清理（可选但推荐）。
- MSW 或 contract test：cookie 签发与恢复。
- 单测：无 cookie → add → 有 cookie；刷新等价 get 恢复。

## 3. 非目标

- Checkout、优惠券、库存预留真源、登录合并 cart（可预留接口）。

## 4. 验收标准

| # | 条目 | 门槛 |
| --- | --- | --- |
| 1 | 首次加购后响应 Set-Cookie（或文档化的 cookie API），后续请求可 get 到同一 cart | **是** |
| 2 | 硬刷新后 cart 行项目仍在 | **是** |
| 3 | GET 首页/PLP/PDP **不**创建新 cart | **是** |
| 4 | 并发/重复提交有测试（幂等或可接受合并策略有断言） | **是** |
| 5 | modules 不直连 cookie/adapter 实现细节 | **是** |
| 6 | 相关 typecheck/test 绿；无 hydration warning（手测或测试注明） | **是** |

## 5. 参考工程对齐要点

- 复现「购物车是服务端权威、浏览器持会话凭证」。
- 不复制 Redux cart slice 与 RTK Query 全量模式。

## 6. 风险

- Cookie 签名密钥必须进 server env，禁止 `NEXT_PUBLIC_*`。
- 与 M2.5 cache：cart **禁止**进入共享 Cache Component（07）。

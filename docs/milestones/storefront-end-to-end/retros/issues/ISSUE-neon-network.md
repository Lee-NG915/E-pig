# 本机 Neon 连接失败与云端验证分离

更新日期：2026-11-02

- 现象：本机官方 WebSocket/HTTPS 路径超时；曾报告 DNS/网络不可达，后续 DNS 可解析但 TCP/HTTPS/WS 仍失败。
- 首次观察：T02/T04 外部数据库检查；没有将本机连接失败归因为交易实现缺陷。
- 根因类：其他（执行环境网络）；本地 PGlite 不能证明 Neon 多连接行为。
- 处理：显式 SQL 通过 Neon 连接器执行并检查交易表；主任务从真实托管 HTTP → Neon/Stripe 验证同 checkout 并发重试、cart lock 409、取消核验解锁，以及桌面支付/回查。无单独应用热修；部署相关实现归 `419990e`。
- 已落地防再发：deployment.md 记录显式迁移、运行时秘密注入及本机连接限制；`scripts/database/vitest.config.ts` 将 opt-in 数据库场景独立，默认本地单测仍不冒充云端并发验收。
- 边界：本机 opt-in 脚本未成功不因云端指定场景通过而改写；实际断网、Pool 重连和任意并发压测仍无完成声明。

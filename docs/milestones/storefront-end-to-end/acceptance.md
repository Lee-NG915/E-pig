## 真实浏览器验收清单

- [ ] 320/375/768/1440 下无横向溢出；商品图片、完整规格选项与顶部市场提示可见且无重叠。
- [ ] 搜索与空结果、列表排序、单规格快加、多规格选择、不可用规格处理。
- [ ] 抽屉与购物车页数量/金额一致；刷新持久化；首个请求失败重试不重复加购。
- [ ] AU 结算表单必填、邮编/州校验、错误文案和键盘可达。
- [ ] Stripe 测试卡支付后由可信服务端确认，购物车清空、订单金额与规格一致。
- [ ] 同浏览器刷新与再次打开订单；没有凭证不能读取订单。
- [ ] 支付取消先核验旧 session 已终结再解锁；支付中不能改购物车。
- [ ] SG/US 路径、币种和私有 Cookie 隔离；禁止创建支付。

## 回归与工具边界

- Netlify 首次构建产生 `.netlify/` adapter vendor 文件，导致原先 `eslint .` 扫描生成物。已与现有 `.next/` 处理方式一致，限定 ESLint / TypeScript 排除 `.netlify/`；未放宽应用源码规则。
- 独立数据库 Vitest 配置最初使用 mergeConfig，数组被拼接而误跑全仓；已改为显式覆盖 include，`vitest list` 仅列出一个外部数据库场景。
- 全量测试与部署打包同时运行时，既有 env-policy ESLint 初始化用例触发 5 秒超时；须在打包结束后独立复核，不将该次执行写成通过。

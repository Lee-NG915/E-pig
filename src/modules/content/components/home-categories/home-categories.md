# HomeCategories

更新日期：2026-11-03

## 场景

首页「按空间购物」：四个一级分类卡片，链向对应 PLP，点击埋点 `home_category_click`。

## 状态矩阵

| 状态 | 可见结果 |
| --- | --- |
| mobile / tablet | 两列图片类目卡，类目名称位于图片外，可独立阅读 |
| desktop | 四列类目卡，保持现有导航顺序 |
| market | 每张卡进入当前市场对应 PLP；链接名称为类目名 |
| reduced motion | 卡片图片不执行缩放过渡 |

## 非目标

Mega Menu、CMS 驱动文案、折扣或试用承诺。

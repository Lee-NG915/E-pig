# ProductReviews

更新日期：2026-11-03

## 用户故事

访客可按评分筛选、按日期/评分排序并展开详细内容。所有内容均显著标注为作者编写的沙箱示例，不是客户评论、购买证明或 Koala 评价，不加入 SEO rating。仅接收 `ProductDemoReview[]`，不采集或提交真实评价。

## 状态矩阵

| 状态 | 行为 |
| --- | --- |
| 默认 | 示例平均分/条数、最新优先、前三条；每条可展开详情 |
| 筛选/排序 | 同步更新列表和数量，重置为前三条；不改变源数据 |
| 展开列表 | 显示所有匹配示例，可收回 |
| 无匹配 | 空态与 Reset rating filter |
| 无数据 | 明确 No demo reviews，无评分或虚假计数 |

# ProductList

## 职责
集合（Collection）的商品列表容器：展示集合标题与件数、排序入口、商品栅格，并在集合为空时给出明确空态。

## 用户故事 / 场景
- 作为浏览者，我希望按集合查看所有商品，以便集中挑选某一品类。
- 作为浏览者，我希望通过排序链接切换列表顺序（名称 / 价格升序 / 价格降序），以便快速比较。
- 作为浏览者，当集合没有商品时，我希望看到清晰提示而不是空白页。

## 状态矩阵
| 状态 | 触发 | 可见结果 |
| --- | --- | --- |
| 有数据 | `products` 非空 | 渲染集合标题、件数、排序链接与商品栅格 |
| 空集合 | `products` 为空数组 | 渲染空态文案与返回首页链接 |
| 默认排序 | `sort` 未传入或不在选项中 | 不高亮任何排序链接 |
| 激活排序 | `sort` 与某选项匹配 | 对应链接高亮并带 `aria-current` |

## 非目标
- 复杂筛选 / facet（M2.3 搜索页）。
- 分页（mock 数据量小，滚动即可）。
- 价格/库存共享缓存（按 Hard Rules 走 request-time）。

## 依赖
- `ProductCard`（同域）负责单品渲染与加购。
- 类型：`ProductListItem`、`ListProductsQuery`（`@/core/contracts/commerce/catalog`）。

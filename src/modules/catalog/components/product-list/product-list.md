# ProductList

更新日期：2026-11-03

## 职责

集合（Collection）的商品列表容器：面包屑、标题与件数、排序入口、URL 筛选、相关集合、商品栅格，空态明确。

## 用户故事 / 场景

- 作为浏览者，我希望按集合查看所有商品，以便集中挑选某一品类。
- 作为浏览者，我希望通过排序链接切换列表顺序，以便快速比较。
- 作为浏览者，当集合没有商品时，我希望看到清晰提示而不是空白页。
- 作为移动浏览者，我希望默认两列快速比较商品，并可切换一列查看大图；切换密度不更改排序、商品数量或已选颜色。

## 状态矩阵

| 状态 | 触发 | 可见结果 |
| --- | --- | --- |
| 有数据 | `products` 非空 | 面包屑 + 标题 + 排序 + 栅格 |
| 空集合 | `products` 为空 | 空态文案与返回首页 |
| 激活排序 | `sort` 匹配 | 对应链接 `aria-current` |
| 相关集合 | `relatedCollections` 非空 | 胶囊链接行 |
| 移动浏览 | 有商品时 | 默认两列，可切换一列；按钮包含名称与选中状态 |
| 桌面浏览 | 宽屏 | 保留现有两列/四列布局，不受移动密度选择影响 |
| 空集合 | 无商品 | 不显示没有作用的密度切换 |
| 筛选中 | 颜色、价格范围、可售 | 排序保留筛选；卡片链接直达匹配规格；筛选变化不遗留旧色板状态 |
| 零匹配 | 有效筛选但无商品 | 与空集合区分，清除入口保留排序 |
| 无效值 | URL 非法或未知颜色 | 解释错误，不展示部分查询结果；可修正或清除 |

## 非目标

分页、facet 数量统计；筛选/排序/无效查询页面由路由层 `noIndex`。

## 依赖

- `PlpBreadcrumb`、`PlpSortNav`、`ProductFilters`、`ProductCard`

# ProductFilters

更新日期：2026-11-03

## 职责

集合页的颜色多选、当前市场价格区间及可售筛选。原生 GET 表单写入 URL；排序值保留。只组合查询参数，不计算价格、库存或变体匹配。

## 状态矩阵

| 状态 | 可见行为 |
| --- | --- |
| 无筛选 | 默认折叠，可打开颜色、价格与可售条件 |
| 已筛选 | 自动展开，已选值来自 URL，提交仍保留排序 |
| 无效 URL | 展开且显示具体原因，不展示部分有效查询的商品；可修正或清除 |
| 未知颜色 | 保留为可取消的 unavailable 选项，避免静默丢弃 |
| 清除 | 清除全部筛选，保留当前排序和市场/集合 |

颜色选项来自未筛选的同一集合。价格为当前市场主货币单位，范围 0–1,000,000。可售为本地沙箱数据，不是实时供应商库存。

## 非目标

不增加 SDK、分页、数量统计、真实库存或促销承诺。
